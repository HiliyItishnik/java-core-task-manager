# Запуск сайта

1. Дважды нажми **start.cmd** в этой папке.
2. Откроется браузер: **http://127.0.0.1:8080**. Если он открылся раньше сервера, обнови страницу через пару секунд.
3. Оставь окно сервера открытым. Для остановки нажми **Ctrl+C** или закрой окно.

Нужен **JDK 17 или новее**, команды `java` и `javac` должны быть в PATH. На компьютере, где создан проект, JDK уже установлен. Maven, Node.js и база данных для запуска не нужны.

Если порт занят, открой PowerShell в этой папке:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\start.ps1 -Port 8081
```

Затем открой **http://127.0.0.1:8081**.

## Возможности

Создание задач с описанием и приоритетом, изменение статуса, отметка выполнения, удаление с подтверждением, поиск по названию, совместные фильтры по статусу и приоритету, счётчики. Интерфейс адаптируется к узкому экрану.

Задачи сохраняются автоматически в `task-manager/data/tasks.txt` и загружаются при следующем запуске. Сайт работает через исходные `TaskService` и `TaskRepository`. Консольная версия также доступна. Запускай одну версию приложения за раз: одновременная работа двух процессов с одним файлом может перезаписать изменения.

Это локальный сайт, сервер доступен только на твоём компьютере. Интернет не нужен для работы; при наличии сети загружается шрифт, иначе используется системный. Развёртывание Java-приложения в интернете не настроено.

## Проверка разработки

После первой сборки можно запустить `node test-web.mjs` из этой папки. Интеграционная проверка использует временный файл данных и не меняет твои задачи. Существующие JUnit-тесты запускаются командой `mvn test` из внутренней папки `task-manager`, если установлен Maven.

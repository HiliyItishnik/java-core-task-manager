# Java Core Task Manager

Консольное приложение на Java для управления задачами. Проект создан для практики Java Core, объектно-ориентированного программирования и подготовки портфолио Java-разработчика.

## Возможности

- Добавление новых задач.
- Просмотр списка задач.
- Изменение статуса задачи.
- Удаление задач по ID.
- Поиск задач по названию без учёта регистра.
- Фильтрация задач по статусу.
- Фильтрация задач по приоритету.
- Сохранение задач в файл.
- Загрузка сохранённых задач при запуске приложения.
- Проверка пользовательского ввода и обработка ошибок.
- Автоматические тесты с использованием JUnit 5.

## Используемые технологии

- **Java 17** — основной язык разработки.
- **Maven** — сборка проекта и управление зависимостями.
- **JUnit 5** — автоматическое тестирование.
- **Java Collections Framework** — хранение и обработка списка задач.
- **Stream API** — поиск и фильтрация задач.
- **Java NIO** — чтение и запись файлов.

## Статусы и приоритеты

Каждая задача имеет один из трёх статусов:

- `NEW` — новая задача.
- `IN_PROGRESS` — задача в работе.
- `DONE` — выполненная задача.

Для каждой задачи также задаётся приоритет:

- `LOW` — низкий.
- `MEDIUM` — средний.
- `HIGH` — высокий.

## Требования

Для запуска проекта необходимы:

- JDK 17 или новее.
- IntelliJ IDEA или другая Java IDE.
- Maven.

## Как запустить проект

### 1. Клонирование репозитория

Открой терминал и выполни:

```bash
git clone https://github.com/Hililytishnik/java-core-task-manager.git
```

Перейди в папку Java-проекта:

```bash
cd java-core-task-manager/task-manager
```

### 2. Открытие в IntelliJ IDEA

Открой папку `task-manager` в IntelliJ IDEA.

Убедись, что в корне этой папки находится файл `pom.xml`, и дождись загрузки зависимостей Maven.

### 3. Запуск приложения

Открой файл:

`src/main/java/ru/portfolio/taskmanager/Main.java`

Нажми зелёный треугольник рядом с методом `main()` и выбери `Run 'Main.main()'`.

После запуска появится консольное меню приложения.

### 4. Запуск автоматических тестов

В терминале, находясь в папке `task-manager`, выполни:

```bash
mvn test
```

Maven скомпилирует проект и запустит автоматические тесты JUnit 5.

## Пример работы

```text
=== TASK MANAGER ===
1. Показать задачи
2. Добавить задачу
3. Изменить статус
4. Удалить задачу
5. Поиск по названию
6. Фильтр по статусу
7. Фильтр по приоритету
0. Выход
Выбери действие:
```

Пользователь выбирает действие, вводит необходимые данные и получает результат в консоли.

## Хранение данных

Задачи сохраняются в файле `data/tasks.txt`.

При запуске приложения сохранённые задачи загружаются автоматически. Добавление задачи, изменение статуса и удаление обновляют файл.

Локальный файл с данными не включается в Git, чтобы пользовательские данные не попадали в публичный репозиторий.

# Java Core Task Manager

Менеджер задач на Java 17 с веб-интерфейсом и консольной версией. Позволяет создавать задачи, расставлять приоритеты, отслеживать выполнение и сохранять данные между запусками.

Веб-интерфейс работает через Java-сервер и использует те же `TaskService` и `TaskRepository`, что и консольное приложение. Проект создан для практики Java Core, объектно-ориентированного программирования и подготовки портфолио Java-разработчика.

## Быстрый запуск сайта на Windows

Для запуска нужен **JDK 17 или новее**. Команды `java` и `javac` должны быть доступны в `PATH`:

```powershell
java -version
javac -version
```

1. Скачай репозиторий через **Code → Download ZIP** и распакуй архив или клонируй его:

   ```powershell
   git clone https://github.com/HiliyItishnik/java-core-task-manager.git
   cd java-core-task-manager
   ```

2. Дважды нажми **start.cmd** в корне репозитория или выполни в терминале:

   ```powershell
   .\start.cmd
   ```

3. Скрипт скомпилирует Java-код, запустит сервер и откроет браузер по адресу [http://127.0.0.1:8080](http://127.0.0.1:8080). Если страница открылась раньше сервера, обнови её через пару секунд.

Оставь окно сервера открытым во время работы. Для остановки нажми **Ctrl+C** или закрой окно.

**Maven, Node.js, IDE и отдельная база данных для запуска сайта не требуются.**

Если порт `8080` занят, выполни из корня репозитория:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\start.ps1 -Port 8081
```

Сайт будет доступен по адресу [http://127.0.0.1:8081](http://127.0.0.1:8081). Дополнительная инструкция: [ЗАПУСК.md](ЗАПУСК.md).

## Возможности

- Создание задач с названием, описанием и приоритетом.
- Просмотр списка задач и счётчиков: всего, в работе, выполнено.
- Изменение статуса и быстрая отметка выполнения.
- Удаление задач с подтверждением в веб-интерфейсе.
- Поиск по названию без учёта регистра.
- Совместная фильтрация по статусу и приоритету в веб-интерфейсе.
- Разделы «Все задачи», «В работе» и «Выполненные».
- Автоматическое сохранение в файл и загрузка при запуске.
- Проверка ввода и отображение ошибок.
- Адаптивный интерфейс для широких и узких экранов.

### Статусы и приоритеты

| Статус | Значение |
| --- | --- |
| `NEW` | Новая задача |
| `IN_PROGRESS` | В работе |
| `DONE` | Выполнена |

| Приоритет | Значение |
| --- | --- |
| `LOW` | Низкий |
| `MEDIUM` | Средний |
| `HIGH` | Высокий |

## Технологии

- **Java 17** — модель задач, бизнес-логика и сервер.
- **JDK HttpServer** — HTTP-сервер без сторонних серверных библиотек.
- **HTML, CSS, JavaScript** — веб-интерфейс без сборки фронтенда.
- **Java Collections и Stream API** — хранение в памяти, поиск и фильтрация.
- **Java NIO** — чтение и запись файла задач.
- **PowerShell и CMD** — сборка и запуск на Windows.
- **Maven и JUnit 5** — сборка и модульные тесты для разработки.
- **Node.js** — отдельная интеграционная проверка веб-сервера.

## Хранение данных

При запуске через `start.cmd` или `start.ps1` задачи сохраняются в **`task-manager/data/tasks.txt`** относительно корня репозитория. Файл создаётся при первом сохранении. Добавление, смена статуса и удаление автоматически обновляют его; при следующем запуске задачи загружаются обратно.

Путь `data/tasks.txt` задаётся относительно рабочей папки Java-процесса. Чтобы консольная и веб-версии использовали одни данные, запускай их из внутренней папки `task-manager`.

Запускай только одну версию приложения за раз: два процесса, работающие с одним файлом, могут перезаписать изменения друг друга. Пользовательские данные и результаты компиляции исключены из Git через `.gitignore`.

## Локальный режим

Сервер слушает только `127.0.0.1`: сайт доступен на компьютере, где он запущен. Публикация в интернете и многопользовательский доступ не настроены.

Для работы с задачами интернет не нужен. При наличии сети интерфейс загружает шрифт Manrope из Google Fonts, а без сети использует системный шрифт.

## Запуск консольной версии

Открой внутреннюю папку `task-manager`, содержащую `pom.xml`, в IntelliJ IDEA или другой Java IDE и выбери JDK 17 или новее. Запусти метод `main()` в файле:

```text
src/main/java/ru/portfolio/taskmanager/Main.java
```

Либо после сборки через `start.cmd` останови веб-сервер и выполни из корня репозитория:

```powershell
cd task-manager
java -cp target/classes ru.portfolio.taskmanager.Main
```

В консоли доступны просмотр, добавление и удаление задач, изменение статуса, поиск и фильтры.

## Тестирование

### Модульные тесты

Нужны JDK 17+ и Maven. Из корня репозитория:

```powershell
cd task-manager
mvn test
```

JUnit-тесты проверяют работу `TaskService`.

### Интеграционная проверка веб-сервера

Нужны JDK 17+ и современная версия Node.js со встроенным `fetch`. Сначала собери проект через `start.cmd`, затем останови сервер. Из корня репозитория выполни:

```powershell
node test-web.mjs
```

Проверка запускает отдельный сервер на порту `18080` и использует временную папку данных, не изменяя пользовательские задачи. Проверяются HTTP-ресурсы, валидация, создание, смена статуса, удаление, русский текст, сохранение после перезапуска и отклонение запросов изменения данных с посторонним `Origin`.
